# 社区行为准则 / Code of Conduct

欢迎不同经验、背景和语言的参与者。讨论围绕问题和证据展开，尊重不同观点，具体指出可以改进的地方。请耐心对待新参与者，接受善意纠正，并尊重他人的时间。

不接受骚扰、歧视、人身攻击、威胁、泄露他人隐私或反复刷屏。未经同意，不公开他人的私人消息或个人资料。本准则适用于仓库的 Issue、PR、Discussions 及与项目有关的社区交流。

维护者 @chuanjianghe1024-cmd 负责处理相关事件，可要求修改内容、限制讨论或移除持续违规的参与者；处理应说明原因，并避免扩大隐私暴露。你可以使用 GitHub 的 Report content / Report abuse 入口报告问题。若需维护者提供私下沟通方式，可先提出不含敏感细节的联系请求；不要为报告违规再次公开受害者信息。涉及维护者自身的投诉可直接使用 GitHub 举报渠道。

## English

People of different backgrounds, experience levels and languages are welcome. Discuss problems and evidence, respect disagreement, give specific feedback, and be patient with newcomers. Accept good-faith corrections and respect other people's time.

Harassment, discrimination, personal attacks, threats, disclosure of private information and repeated spam are unacceptable. Do not publish private messages or personal details without consent. This policy covers repository Issues, PRs, Discussions and project-related community interactions.

The maintainer, @chuanjianghe1024-cmd, handles reports and may request edits, limit discussions or remove persistent offenders, with an explanation and attention to privacy. Use GitHub's Report content / Report abuse controls to report incidents. You may request a private contact route without posting sensitive details. Complaints involving the maintainer can go directly through GitHub's reporting channels.
