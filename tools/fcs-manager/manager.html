本机 Gateway

统一发现 USB / Wi-Fi 设备，管理传感器、插件与重装。FC 只需勾选订阅。



USB 管理



设备插件
插件运行在 C3 上。仅安装可信插件，安装后默认禁用。









网关插件 / 脚本
这些脚本运行在 Gateway，不占用 C3 存储。当前支持受限脚本包；安装及验证使用网关 CLI。
创建：FluentControl.FcsGateway.exe --script-create FILE.json
验证：FluentControl.FcsGateway.exe --script-validate FILE.json
模拟执行：FluentControl.FcsGateway.exe --script-test FILE.json SIGNALS.json


USB 重装 C3
适用于 4 MB ESP32-C3 + BH1750（SDA GPIO4 / SCL GPIO3）。必须先用 Thonny 首装并初始化 FCS 标识。只接受带标识分区的新版完整恢复 ZIP。
重装会清空 Wi-Fi、插件和用户设置。只选择你信任的恢复包。摘要检查用于发现文件损坏，不代表签名认证。
连接 USB 数据线。若无法连接，按住 BOOT，按一下 RESET 或重新插电，再松开 BOOT；完成后必要时按 RESET。
尚未验证；普通 C3 不可重装。
