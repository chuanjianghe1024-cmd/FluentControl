# 环境光自适应与用户偏好学习（计划）

状态：2026-10-14 用户希望接入，等待自制 USB 光照硬件完成后实施/实测；已提供动态 HTTP 光照订阅、独立光照/时间曲线、日出日落及显式启用的自动调节，详见 [adaptive-presets.md](adaptive-presets.md)；USB/BLE 桥接、硬件实测和偏好学习尚未实现。

## 参考证据

[追光护眼使用教程](http://www.xabyb.com/2021/09/14/%e4%bd%bf%e7%94%a8%e6%95%99%e7%a8%8b/)说明手动调整可用于学习偏好；每 0.5 秒采样，连续三次近似才接受读数；模型可重置。教程没有公开学习算法、模型格式或源码许可。只参考交互与稳定性目标，不复制私有软件/固件，也不声称其算法就是以下设计。网页宣传的护眼效果不作为产品医疗承诺。

## FC 拟采用的行为

- 统一光照来源接口：Windows 内置 ALS 和用户自制 USB 设备；显式选择来源，读数带 lux、时间戳、有效性和传感器身份。无数据/断开立即暂停自动写入，保留当前亮度。
- 默认关闭。开启后使用本地每屏独立的 lux→亮度曲线；初始可配置，不能将一台显示器百分比当另一台的实际亮度。SDR/HDR 分开记录；更换传感器或摆放位置后允许重置/校准。
- 用户在光照稳定时手动调整，松开滑块且设备回读成功后形成候选样本。提供“记住这次调整”与“仅临时调整”，并有学习开关、撤销最近样本、查看/重置曲线。
- 只学明确的用户操作；程序自身写入、场景重放、Windows 电源策略、启动恢复和未知外部变化不作为训练样本。不会把控制器自己的输出反复当作新偏好。
- 第一版使用本地锚点与 log(1+lux) 域分段插值；采用亮度上下限、样本权重与有限局部调整。无需云端模型、账号或上传。具体过滤窗口、迟滞、变化阈值和渐变速度通过实测调优，不把参考项目的采样参数直接视为最佳值。
- 用户操作优先，手动后进入保持期，避免自动控制立刻抢回。明确由 FC 还是 Windows 管理自动亮度；用户自行选择，不静默修改系统策略。
- 内屏用 Windows WMI，外屏用 DDC；仍通过现有 gate/generation、节流和错误隔离，不绕过连接验证。传感器采样频率不等于 DDC 写入频率。
- 暖色偏好可后续独立加入，BH1750 只能提供照度，不能推断环境色温/蓝光含量。软件色温的 HDR/ACM、恢复与外部所有权限制继续生效；这不授权当前版本自动写 Gamma。

## 验收

同照度逐渐接近用户偏好；单次误操作可撤销；暗/亮突变与手遮传感器不闪烁；断线、过期读数、睡眠、HDR 切换、屏幕热插拔后不重放旧指令；每屏互不污染；手动操作不被立即覆盖；学习数据仅保存在本机并支持导出、重置。
