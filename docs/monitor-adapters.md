# 型号适配与采集助手

每台显示器的“型号适配”入口负责查找、安装和移除适配包。“采集 / 提交适配报告”负责收集实机证据。它们独立于总配置和型号预设库。

## 用户流程

1. 打开显示器的“型号适配”，在线查找与完整 PnP 型号 ID、原始 VCP 固件版本精确匹配的已审核包。
2. 阅读适配说明和验证依据，点击“安装并使用”。刷新后应用该包；本地持久化，后续启动无需联网。移除后刷新恢复通用控制。
3. 无匹配包时打开采集助手，填写 HDMI/DP/USB-C、扩展坞/KVM、HDR/SDR、厂商软件等实际环境。
4. 采集基线；用显示器实体菜单只改一项，填写原厂名称（如“色温 6500 K”），记录变化。可重复记录，最多 24 次，每次均与本次基线比较。
5. 导出并前往网站提交。在浏览器使用 GitHub/Google 登录，选择刚导出的 JSON；报告进入私有待适配队列，维护者空闲时可研究并更新进度。

固件无法读取时不会跨版本猜测匹配，仍可提交报告并在备注写出菜单中看到的版本。网站代码需要先配置 PG、Hyperdrive、OAuth 与域名并部署；当前源码不代表生产服务已经就绪。

## 采集边界

- 原始值保留当前值、最大值、类型、高字节、原生错误码及耗时，不转换为 UI 百分比。基线读取一次原始能力串并绕过常规能力缓存，后续观察复用此能力元数据，但参数每次从硬件读取。
- 已知标准可读参数进行顺序读取；未知私有码、恢复出厂和按键动作只列出，不探测，不遍历所有编码，更不尝试写入。声明支持、读取成功和可安全写入不是一回事。
- 对比区分数值与读取状态；读取失败不会变成 0。单项失败继续采集其他项，已断开或不同设备不能混为同一实验。取消在当前原生调用结束后停止，不提前销毁句柄。
- 采集期间暂停 FC 总配置切换和桌面写入，关闭独立 OSD；主窗口弹窗阻止常规调节。外部厂商软件仍需用户自行暂停，避免污染观察。
- 本机自动保存的报告位于 `%LocalAppData%\FluentControl\Diagnostics`。默认导出与自动保存均排除设备实例、系统显示器路径和原始能力串；可显式勾选附带原始串，厂商扩展字段可能含标识信息。
- 网站报告严格私有，只允许提交者与配置的适配维护者访问；报告不自动发布，也不自动授权写指令。

## 数据型适配包 v1

`format = fluentcontrol.monitor-adapter`，`version = 1`。未知字段拒绝；不加载 DLL、脚本、动态表达式或第三方下载地址。客户端仅请求固定的 `https://fctrl.app/api/v1/adapters`，禁止重定向，限制响应 256 KiB。

| 字段 | 规则 |
| --- | --- |
| `id` / `revision` | 3–80 位小写字母数字及连字符；修订号 1–1,000,000 |
| `modelId` / `modelName` | 完整 7 位大写型号码；型号名最多 120 字符 |
| `firmwareVersions` | 1–32 个经过验证的原始 `major.minor` 版本，不能使用通配符 |
| `notes` / `evidence` | 使用说明及实机/厂家协议验证依据，各最多 2000 字符 |
| `controls` | 最多四项：`color-preset`、`display-mode`、`scaling`、`osd-language`；每项明确列出合法数值与名称，不根据最大值猜测枚举 |
| `nativeMenu` | 可选 `open/close/up/down/left/right/enter` 指令；允许经验证的 `0x03` 或厂商扩展 `0xE0–0xFF`，16 位值。相同编码可对应不同按键 |

`controls` 保留原有读取、范围验证和回读机制；没有成功读取的参数不会因为安装了包就凭空显示可控。原厂菜单按键位于“型号扩展”，执行需要确认、仅发送给所选设备，不保存到总配置/分享文件，也不参与聚合控制。

安装只存数据，不发送硬件写入；安装包必须匹配当时读取的型号与固件。固件变化后不再启用旧包。文件损坏时回退通用控制，用户可重新安装。在线撤回停止后续下载，已安装离线包由用户主动移除。

首版不自动逆向厂商协议，也不附带猜测生成的真实型号适配包。新增适配必须有实机或明确厂家协议证据；不要把 `0xCA` 当“打开菜单”，也不能从采集差异直接推断未知指令可写。

## 网站维护

独立 `FluentControl-Web` 仓库提供 `002_adapters.sql`、报告提交页和 `/adapters/review` 维护台。环境变量 `ADAPTER_REVIEWER_IDS` 使用经核实的 Auth.js `users.id`，逗号分隔，未配置时维护权限关闭。

报告状态：待适配 → 研究中 → 已适配/关闭。维护者上传适配包草稿，完成验证后发布；内容按 revision 不可覆盖，可撤回并发布新 revision。网页端所有写操作校验会话、Origin 与角色；普通报告提交者没有发布指令的权限。

协议及匹配/权限测试分别在两仓库维护；C# 纯逻辑测试不替代真实显示器测试。WinUI 自动回归使用明确标记的模拟报告。
