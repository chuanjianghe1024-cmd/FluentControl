# FluentControl v0.3.135

本次版本把光照传感器接入、采样间隔和历史记录集成到 FC，并更新 Windows 风格托盘菜单。

## 新增与改进

- **本地 USB 光照订阅**：发现兼容 RP2040 设备，或手动指定 COM 端口；保存设备身份，自动模式下端口变化后重新寻找同一设备，无需运行 Python 桥接程序。
- **采样间隔**：支持滑块、数字输入及最快/1 秒/5 秒/10 秒/1 分钟/10 分钟预设；范围 0.2 秒至 24 小时。最快档是请求间隔，不保证每秒五个新样本。
- **光照历史**：本机保存原始读数与数据缺口，按来源分页查看；总容量最多 64 MiB，满后轮换最早分段。记录可独立于自动亮度运行，关闭 FC 或电脑休眠期间不补造记录。
- **自动调节**：保留 HTTP(S) 光照订阅、模拟来源、定时和日出日落曲线，以及手动保持、HDR 限制和写入节流。
- **内屏与主题**：纳入预览版的 Windows WMI 内屏亮度接口，以及跟随系统/浅色/深色应用主题；按设备身份和驱动能力开放控制，实际笔记本效果仍待验证。
- **托盘菜单**：WinUI Fluent 风格、图标和浅色/深色主题；主面板隐藏时也能操作；修复自定义透明背景在切换主题时触发的崩溃。

## 使用和升级

下载安装下方 Setup EXE（推荐）或 MSI，升级保留个人设置与原安装目录。附件为 Windows x64 离线安装包，未做 Authenticode 签名，SHA-256 摘要见 SHA256SUMS.txt。

RP2040 需先通过 Thonny 写入兼容 MicroPython 程序，再关闭 Thonny 和旧桥接程序。在 FC 设置 → 自动调节预设 → 光照强度中发现并订阅设备。添加来源只启用记录，不自动启用亮度调节；确认目标显示器与曲线后手动开启。

配套固件与接线说明位于 [FluentControl-Sensors](https://github.com/chuanjianghe1024-cmd/FluentControl-Sensors)，当前私有，仅授权账户可访问。公开源码中也包含 [RP2040 原型程序](https://github.com/chuanjianghe1024-cmd/FluentControl/blob/d7221cdfbca31a6a584da58aef250cb24d649021/tools/light-source/rp2040/main.py)。

## 验证与边界

来源：主干提交 `d7221cdfbca31a6a584da58aef250cb24d649021`，Windows build #135。完整 Windows 构建、自动化界面回归、MSI 和 Setup 安装验收通过后提升同一构建附件，未重新打包。

实体传感器与 FC 的完整联动、实体多显示器及混合 DPI 仍需实测。自动发现当前限定 RP2040；C3/CH552 固件、BLE/HID 接入、FC 更新硬件程序及硬件历史回灌尚未实现。RP2040 的 64 条 RAM 缓存断电丢失。长采样间隔在下次读取时才发现掉线，三样本滤波预热也随间隔延长。

This release integrates local light-sensor subscriptions, sampling controls and bounded history into FC, and refreshes the tray menu.

- Discover compatible RP2040 USB probes or select a COM port. Bind a stable device identity; automatic mode rediscovers the same probe after port changes. No running Python bridge is required.
- Configure sampling with a slider, numeric input and presets from 0.2 seconds to 24 hours. The minimum request interval is not a guaranteed measurement rate.
- View paginated local light history with a 64 MiB rolling capacity across sources. Recording is independent of brightness adjustment; gaps are preserved rather than filled.
- Retain HTTP(S) feeds, simulation, clock/sunrise scheduling, manual holds, HDR restrictions and write throttling.
- Include the preview’s identity-matched Windows WMI panel brightness and system/light/dark app themes. Physical notebook validation remains pending.
- Use a themed WinUI Fluent tray menu even while the main window is hidden; fix a custom-backdrop crash during theme changes.

Use the Windows x64 Setup EXE or MSI below. Upgrades preserve personal settings and the existing installation path. Installers are unsigned; SHA256SUMS.txt provides integrity hashes.

Flash the compatible RP2040 MicroPython program first, close Thonny/other serial clients, then discover the sensor in FC settings. Adding a subscription enables recording but leaves automatic brightness off.

The exact main build #135 (`d7221cdfbca31a6a584da58aef250cb24d649021`) passed Windows, automated UI, MSI and Setup validation before promotion. Physical sensor-to-FC integration and real multi-monitor/mixed-DPI behavior remain unverified. C3/CH552 firmware, BLE/HID, firmware updates from FC and hardware-history backfill are not implemented. Firmware history is volatile; long intervals delay disconnect detection and filter warm-up.
