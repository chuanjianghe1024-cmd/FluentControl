## 中文

本版汇总正式版 **v0.3.92** 之后的更新，首次正式提供 Win11 风格安装向导，同时完善手动更新、系统色温恢复与社区协作文档。

### 新版安装向导：从安装开始保持 Fluent 风格

- **系统、浅色、深色主题**，支持简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español。
- 首次安装可选择本地目录，包括中文和空格路径；使用现代系统文件夹选择器，并可设置“随 Windows 启动”。
- 安装成功后，由你点击 **“启动 FluentControl”** 打开应用，也可以直接关闭；静默安装、修复、取消和卸载不会自动启动应用。
- 再次打开同版本 Setup 可修复或卸载；卸载需要确认。升级保留原目录和个人配置，自启动选项以当前实际设置为准。
- 遇到文件占用时可以关闭占用程序后重试，或取消并回滚，不强制结束其他应用。

### 完整离线，下载体积接近原 MSI

| 安装包 | 大小 | 适合谁 |
| --- | --- | --- |
| **Setup.exe** | **53.48 MB**（53,475,263 字节） | 推荐日常安装，使用新版 Fluent 向导 |
| **MSI** | **50.70 MB**（50,696,405 字节） | 使用传统向导或现有 MSI 部署流程 |

相比首版现代安装器的开发构建 #115（112.49 MB），新版 Setup 缩小约 **52%**，比同版 MSI 只多约 **2.8 MB**。这是移除重复运行时和提高压缩率的结果，保留完整离线安装内容。安装前端复用受支持 Windows 自带的 .NET Framework 4.8，主应用所需运行库仍包含在包内，无需联网补下载。

### 更新与显示控制更稳妥

- 新版手动更新优先使用官方 Setup，仍兼容只有 MSI 的旧 Release；检查文件来源、大小和 SHA-256 后，由用户选择安装。
- 修复软件色温写入未确认、随后恢复又失败时可能丢失恢复记录的问题。
- 设置或恢复颜色前再次核对其他程序是否改动了颜色曲线，减少覆盖外部颜色设置的风险。
- 设备刷新或 HDR 切换后，取消排队中的旧总配置请求，避免继续应用过期操作。

显示控制修复不增加新的型号适配，也不代表所有显示器都能远程导航原厂 OSD。实体 HKC、HDR、颜色曲线及混合 DPI 体验仍需实机验证。

### 文档与开源协作

补齐 MIT 许可证、中英文 Wiki、贡献指南、问题模板与分层 CI。社区贡献通过 PR，维护者仍保留直接推送主干的能力；需要强制评审时可按维护指南切换。

## English

This release brings together the changes since **v0.3.92**, introducing the Fluent installer as a stable download, improving manual updates and software color recovery, and completing the community documentation.

### A Fluent installation experience

- System, light and dark themes, with eight languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French and Spanish.
- Choose a local installation folder through the modern Windows folder picker, including Unicode and space-containing paths, and choose whether to start with Windows.
- Launch the application explicitly after successful installation, or simply close Setup. Quiet installation, repair, cancellation and uninstall do not launch the app.
- Reopen the same Setup version to repair or uninstall, with uninstall confirmation. Upgrades preserve the existing folder and personal settings, and respect the current startup choice.
- Retry after closing a program that holds installation files, or cancel and roll back. Setup does not forcibly close unrelated applications.

### Fully offline, close to MSI size

| Package | Size | Best for |
| --- | --- | --- |
| **Setup.exe** | **53.48 MB** (53,475,263 bytes) | Recommended everyday installation with the Fluent wizard |
| **MSI** | **50.70 MB** (50,696,405 bytes) | The traditional wizard or existing MSI deployment workflows |

Setup is about **52% smaller** than the initial modern-installer development build #115 (112.49 MB), adding only about **2.8 MB** over this release's MSI. Removing the duplicate frontend runtime and improving compression retains the complete offline payload. The frontend uses Windows-provided .NET Framework 4.8 on supported systems; the main application's runtime remains included. No runtime download is required.

### More reliable updates and display controls

- Manual updates in this version prefer the official Setup, retaining compatibility with older MSI-only releases. Validate the source, size and SHA-256 before the user chooses to install.
- Preserve software color recovery information when an unconfirmed write is followed by a failed restoration.
- Recheck external color-curve changes immediately before applying or restoring colors, reducing the risk of overwriting another program's settings.
- Cancel queued global-profile requests after device refresh or an HDR transition, preventing stale actions from continuing.

These fixes do not add new monitor-specific native OSD navigation. Physical HKC displays, HDR/color behavior and mixed-DPI experience still need hardware validation.

### Documentation and contributions

Add the MIT license, bilingual Wiki, contribution guides, issue templates and layered CI. Community contributions use PRs while the maintainer retains direct main-branch pushes; the maintenance guide describes how to enable mandatory reviews later.
