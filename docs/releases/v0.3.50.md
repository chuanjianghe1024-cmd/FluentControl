# FluentControl v0.3.50 · 第二个正式版本

本版汇总首发 **v0.3.33 → v0.3.50** 之间的更新：新增可复用的型号配置库、每屏软件 OSD 和型号适配采集，修复桌面组件、缩放及安装升级问题。

直接发布此前通过 Windows 验收的 **0.3.50 原始安装包**，保留其版本号与文件校验值。已经安装同一个 0.3.50 测试包的用户无需重装。

## 下载与升级

下载附件 **FluentControl-0.3.50-x64.msi**，从托盘菜单彻底退出 FluentControl 后双击安装。安装到当前用户目录，无需管理员权限；支持从旧 MSI 覆盖升级，保留个人配置和已有自启动选择。旧便携版迁移后，请重新启用自启动以更新路径。

单文件离线安装包 **48.07 MiB**，自带必要运行库，无需预装 .NET 或 Node.js。面向 Windows 11 x64，安装器最低门槛为 Windows 10 2004 x64。首次迁移型号配置库前会自动备份旧 `user-state.json`。

## 相比 v0.3.33 新增了什么

### 总配置与型号配置库

- 总配置保存并切换显示器、声音/麦克风音量与静音、鼠标速度和指针大小；桌面面板、托盘及快捷键同步切换完整状态，离线设备参数继续保留。
- 显示器预设按型号自动分组；同型号屏幕可以共用预设，每块屏幕也可分别选择。每屏提供“选用配置 / 保存当前”。
- 选择其他型号的预设时，显示兼容数量，仅应用目标支持的参数与选项，并支持另存为当前型号的配置。
- 总配置保存参数快照与来源引用；编辑或删除型号库预设不会改变已保存的总配置。旧场景自动迁移并保留备份。
- 型号预设支持批量导入导出、离线导入和相同内容去重；分享文件可附带厂商、固件、MCCS、参数范围及离散选项等能力信息，兼容旧格式。音频、鼠标及本机设备身份留在本地。

### 每屏 FC 软件 OSD

- 为每台显示器提供独立的 FC 软件菜单，复用该屏实际可用的控制项；可按 Esc 关闭，关闭后取消尚未执行的调节。
- 区分 FC 软件菜单、显示器原厂 OSD 的启用/语言设置和原厂菜单导航，避免将“允许使用原厂菜单”误解为“弹出原厂菜单”。

### 数据型适配包与只读采集

- 增加独立于场景预设的型号适配入口：按完整型号和固件精确匹配，支持查询、安装、离线使用和移除适配包。
- 适配包只包含受校验的数据，可补充经验证的选项映射及原厂菜单指令，不加载第三方脚本或 DLL。私有菜单操作保留确认，不进入总配置或批量控制。
- 无适配包时可采集只读基线，手动调整显示器实体菜单后记录变更，比较原始数值、范围与错误状态，保存或导出诊断报告。未知私有码不通过猜测写入来探测。
- 导出报告默认排除设备实例 ID、序列号和本机路径；原始能力字符串需主动选择。网站报告提交使用浏览器登录及显式选文件，不静默上传。

**在线服务状态：** 配套网站的报告队列、审核、发布和撤回功能已完成开发，但尚未部署上线。本次桌面发布不代表在线查询、报告提交或社区服务已可用。具体型号的原厂 OSD 指令仍需实机验证后制作并发布适配包，本版未附带未经验证的私有指令包。

## 修复与体验改进

- **Win+D 桌面组件：** 修复“显示桌面”时组件被最小化或被桌面覆盖的问题；保持锁定、不抢焦点，恢复应用窗口后回到普通应用下方。
- **高 DPI / 4K 缩放：** 主窗口按当前屏幕 DPI 调整大小；显示器识别名称自动换行、提示框按内容增高。FC 软件菜单和准星按目标屏幕缩放定位，支持负坐标副屏并限制在可用区域。
- **安装与升级：** 禁用新安装包通过 Restart Manager 自动关闭/重启其他程序，保留真实文件占用提示；调整旧版移除顺序，避免先删除未变更运行库而再次触发旧安装器的关闭策略。升级操作仍支持事务回滚。
- **自启动：** 修复快捷方式尚未释放就校验或移动导致的失败；临时文件独立暂存，短暂占用有限重试，失败保留原快捷方式。
- **色温预设：** 统一原始 VCP 读写与读回校验，区分 Windows 色温枚举和 MCCS 预设，处理容差高字节及延迟读回；旧配置继续兼容。
- **桌面整体控制：** 扩展到实际支持的安全调节项，包括色温预设、RGB、Gamma、饱和度和显示模式。离散选项取并集，共同支持项一起应用，部分支持项标明目标屏幕。

## 验证与已知限制

- Windows build #50 已通过设备逻辑、原生鼠标设置、WinUI 构建与启动、安装后模拟设备界面、托盘、真实 Shell Win+D、MSI 安装/升级/卸载及个人配置保留检查。
- 安装回归覆盖旧策略升级、较低版本程序文件替换、未变更运行库保留、真实文件占用时取消，以及独立运行程序在安装/升级/卸载期间存活。
- 尺寸计算覆盖 4K 的 100%、125%、150%、175%、200% 缩放；原生窗口和长文字布局在测试屏幕 **100%** 下验证。实体 **4K / 150%** 及混合 DPI 多屏仍需实机复测。
- **安装包未做 Authenticode 签名**，Windows 可能提示发布者未知或 SmartScreen；SHA-256 校验不替代代码签名。
- DDC/CI、HDR/ECO 限制、厂商功能和私有指令的支持取决于具体显示器及连接链路，不代表所有型号均已适配。动态厂商 SDK、硬件准星、游戏 FPS、自动应用场景等仍未提供。
