# FluentControl v0.3.50

**第二个正式版本 · Second release**

[中文](#中文) · [English](#english) · [项目介绍 / About](https://github.com/chuanjianghe1024-cmd/FluentControl#readme)

## 中文

**把多屏调节变成一次操作，让常用设置随时可用。** FluentControl 将显示器、声音、麦克风和鼠标集中到一个 Windows 控制面板。本版汇总 **v0.3.33 → v0.3.50** 的更新，重点是可复用的型号配置、每屏软件菜单，以及桌面组件和安装体验。

### 本版亮点

- **一次切换整套工作状态。** 总配置保存显示器参数、声音和麦克风的音量与静音、鼠标速度及指针大小，可从主窗口、桌面面板、托盘或快捷键切换；暂时离线的屏幕也保留原有设置。
- **好用的屏幕配置可以反复使用。** 型号配置库按显示器型号整理预设，同型号屏幕可共用，也可分别选择。借用其他型号的配置时会提示兼容范围，仅应用目标支持的参数；修改库中预设不会改变已经保存的总配置。
- **每台屏幕都有自己的 FC 软件菜单。** 在对应屏幕上打开常用调节项，减少来回切换主窗口；按 Esc 即可关闭。软件菜单与显示器自带的原厂 OSD 是不同功能，原厂菜单遥控需要对应型号的已验证适配。
- **配置分享更方便。** 型号预设支持批量 JSON 导入导出、离线使用和重复内容识别，也可附带显示器能力信息。音频、鼠标及本机设备身份保留在本地。
- **为更多显示器适配做好准备。** 新增按型号和固件匹配的数据型适配包框架，以及只读采集助手。遇到不支持的功能，可手动调整实体菜单并记录前后差异，导出报告供后续研究；导出默认排除序列号、设备实例和本机路径。

### 解决了哪些问题

- **按 Win+D 后桌面组件消失：** 修复组件被最小化或桌面覆盖的问题，保持锁定状态且不抢焦点。
- **高分屏界面偏小、识别文字截断：** 窗口按屏幕缩放比例调整，长名称自动换行，提示框随内容增高；改进软件菜单在不同屏幕上的定位。
- **安装时要求关闭无关程序：** 调整安装和升级流程，避免安装器自动关闭或重启其他程序，同时保留真实文件占用提示和升级回滚。
- **自启动设置偶尔失败：** 修复快捷方式文件短暂占用引起的问题。
- **色温预设读写不一致：** 改进色温编码处理和写后回读校验；具体型号仍可能拒绝指令或返回不同值，不能据此承诺所有显示器都已适配。
- **桌面整体控制可调项目不足：** 增加实际支持的色温、RGB、Gamma、饱和度和显示模式等控制，并提示哪些屏幕支持所选选项。

## English

**Control multiple displays together and keep everyday settings within reach.** FluentControl brings monitor, audio, microphone and mouse controls into one Windows panel. This release covers **v0.3.33 → v0.3.50**, focusing on reusable monitor presets, per-display software menus and a smoother desktop and installation experience.

### Highlights

- **Switch your whole setup at once.** Overall profiles save monitor settings, audio and microphone volume/mute, mouse speed and pointer size. Apply them from the main window, desktop panel, tray or keyboard shortcuts. Settings for disconnected displays are retained.
- **Reuse monitor settings.** The model preset library groups presets by monitor model. Share a preset across matching displays or choose one for each screen. Cross-model presets show compatibility and apply only supported settings. Editing a library preset leaves previously saved overall profiles intact.
- **A dedicated FC software menu on each display.** Open supported controls on the screen you want to adjust and press Esc to close. This is separate from the monitor's built-in OSD; remote navigation of the manufacturer's menu requires a verified adapter for that model.
- **Share presets more easily.** Batch JSON import/export, offline use and duplicate detection are supported, with optional monitor capability information. Audio, mouse and local device identities stay on your computer.
- **Help expand monitor compatibility.** A data-only adapter framework matches exact models and firmware. The read-only capture assistant records changes while you adjust the physical menu, producing reports for later research. Exports exclude serial numbers, device instance IDs and local paths by default.

### Fixes and improvements

- **Desktop panel disappearing after Win+D:** fixed minimizing and desktop coverage issues while keeping the panel locked and avoiding focus changes.
- **Small windows and clipped display names at high DPI:** windows respect display scaling, long names wrap and identification panels grow with their content. Software menu placement across displays is improved.
- **Installer asking to close unrelated apps:** installation and upgrade behavior now avoids automatically closing or restarting other programs, while retaining real file-lock warnings and upgrade rollback.
- **Intermittent startup setting failures:** fixed temporary shortcut file-lock issues.
- **Color temperature read/write mismatches:** improved value handling and read-back checks. Individual models may still reject commands or return different values; this does not establish compatibility with every monitor.
- **More linked desktop controls:** supported color temperature, RGB, gamma, saturation and display modes are available, with indicators for options supported by only some displays.

When moving from the portable version, re-enable startup to update its path. **If you already installed the same 0.3.50 test package, you do not need to reinstall.**

### Before you install

- Monitor controls depend on DDC/CI support throughout the device and connection path. HDR or power-saving modes may lock some settings.
- **Online model lookup, report submission and community services are not live yet.** This release provides the adapter framework and local capture tools, without unverified private commands for the manufacturer's OSD.
- The installer is not code-signed. Windows may show an unknown publisher or SmartScreen prompt. A file checksum is not a substitute for a signature.
- Windows automated checks cover the UI, tray, Win+D, installation/upgrades and settings preservation. Physical **4K / 150%**, mixed-DPI setups and specific monitor controls still need hardware testing.
- Vendor SDKs, hardware crosshairs, game FPS and automatic profile switching by application are not included. See the [project roadmap](https://github.com/chuanjianghe1024-cmd/FluentControl#readme) for future directions, separate from this release's features.

Report issues or contribute compatibility findings through [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues), including model, firmware, connection, HDR state and reproduction steps. Review diagnostic files for personal information before sharing.
