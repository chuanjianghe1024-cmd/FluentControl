# FluentControl v0.3.60

## 中文

**常用设置更容易找到，新版也能从应用里检查。** 本版在 v0.3.57 的系统音量与桌面双击前置改进基础上，增加手动更新，并整理设置导航。

### 本版亮点

- **手动检查 GitHub 正式版。** 打开“设置 → 关于与更新”，查看当前版本并点击“检查更新”。有新版时可查看发布说明，下载 Windows x64 MSI，再自行选择“退出并安装”。应用启动时不自动检查，不需要 GitHub 账号。
- **下载过程可取消、可重试。** 只接受本仓库正式 Release 中匹配的安装包，下载完成与安装前分别校验。错误或不完整的文件不会进入安装步骤；网络异常、请求受限或缺少可校验安装包时会明确提示。
- **设置分成六个子菜单。** 常规、显示器、全局快捷键、桌面控制面板、软件准星、关于与更新各自成页；导航固定在上方，长内容独立滚动。刷新和重建设置时保留当前分类，检查更新期间也能切换页面。
- **八种语言同步更新。** 新增导航、下载、取消、安装与错误提示均提供本地化。
- **仓库介绍更直观。** 中英文 README 加入统一品牌分享图、版本与构建状态、下载入口和更明确的 DDC/CI 多屏控制说明，并提供中英文问题反馈模板。仓库简介、主题标签和 Social preview 素材也已准备；这些仓库设置需要单独应用，不随安装包更改。

本版沿用 v0.3.57 的系统“音量”“输入”及桌面双击立即前置行为。若仍使用更早的设备音频总配置，请调整音量后更新一次相应配置。

通过 Windows 编译、更新逻辑与模拟网络检查、设置和更新界面回归、桌面双击及 Win+D、托盘、MSI 安装/升级/卸载验收。更新测试覆盖版本比较、错误来源、校验失败、截断下载、取消和请求失败；不会在测试中执行模拟安装文件。

安装包仍未签名，SHA-256 校验用于确认下载内容一致，不能代替发布者签名。显示器原厂 OSD、实体 4K / 150% 和虚拟音频驱动仍按各自硬件验证状态提供支持；在线型号分享与报告服务尚未上线。遇到问题请到 [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues) 反馈。

## English

**Find settings faster and check new releases inside the app.** Building on v0.3.57’s system audio controls and immediate desktop-panel activation, this release adds manual updates and settings navigation.

### Highlights

- **Check official GitHub releases on demand.** Open Settings → About & updates to see the current version and check for updates. Read release notes, download the Windows x64 MSI, then choose Exit and install. There is no automatic startup check and no GitHub account is needed.
- **Cancel or retry downloads.** Only a matching installer from this repository’s stable Release is accepted. Downloads are verified on completion and again before installation. Corrupt or incomplete files cannot proceed; network problems, request limits and unavailable verifiable installers have clear messages.
- **Six settings sections.** General, Displays, Global shortcuts, Desktop controls, Software crosshair, and About & updates each have their own page. Navigation stays above independently scrolling content. Refreshes preserve the selected section, and navigation remains available during update checks.
- **Eight-language coverage.** New navigation, download, cancellation, installation and error messages are localized.
- **A clearer repository introduction.** The bilingual README adds a consistent branded sharing image, release/build badges, downloads and clearer DDC/CI multi-monitor information. Bilingual issue templates help with feedback. Repository description, topic suggestions and Social preview assets are prepared; those GitHub settings require separate application.

### Download and upgrade

**[Download FluentControl-0.3.60-x64.msi](https://github.com/chuanjianghe1024-cmd/FluentControl/releases/download/v0.3.60/FluentControl-0.3.60-x64.msi)** · 48.12 MiB · Windows x64 · Offline MSI

Earlier versions do not have the update page. Exit the old app from the tray, then download and run this installer. Personal settings and startup preferences are retained. Future releases can be checked manually from About & updates. Installation continues through the existing MSI interface for you to complete.

System Volume/Input and immediate double-click desktop activation from v0.3.57 remain included. If you still use older device-bound audio profiles, set the desired audio values and update those profiles once.

### Validation and limits

Validated through Windows compilation, update logic and simulated network checks, settings/update UI regression, desktop double-click and Win+D, tray behavior, and MSI installation/upgrade/uninstallation. Update tests cover version comparison, wrong sources, failed checksums, truncated downloads, cancellation and request failures. Test installers are never executed as updates.

The installer remains unsigned. SHA-256 verifies download consistency; it does not replace publisher signing. Native monitor OSD, physical 4K at 150% and virtual audio drivers remain subject to their hardware-validation status. Online model sharing and report submission are not live yet. Report problems through [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues).
