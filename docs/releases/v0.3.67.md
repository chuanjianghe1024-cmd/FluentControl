## 中文

本版完善安装引导：选择安装位置、决定是否随 Windows 启动，并可在安装完成后直接打开 FluentControl。

### 本版更新

- **自定义安装目录。** 新安装可输入路径或通过“浏览”选择本地文件夹，支持中文和空格路径。默认位置保持不变，选择的目录需有当前用户写入权限。
- **安装完成后立即启动。** 完成页默认勾选“立即启动 FluentControl”，点击“完成”后打开主面板；取消勾选则只结束安装。静默安装、修复、卸载和需要重启时不会自动打开应用。
- **安装时选择开机启动。** 新安装默认不勾选“随 Windows 启动”。启用后，登录 Windows 时在托盘运行；安装后仍可在“设置 → 常规”里开关。升级读取现有启动项，保留选择，也允许在向导里取消。
- **升级沿用原目录。** 自动找回现有安装位置，避免创建第二套程序；如需迁移，先卸载再选择新目录安装，个人配置会保留。
- **宣传图统一新版图标。** README 与仓库分享图素材改用应用现有的三滑轨图标。GitHub Social preview 设置仍需单独上传。

## English

This release improves setup: choose an installation folder, decide whether FluentControl starts with Windows, and open the app directly when installation finishes.

### What's new

- **Choose the installation folder.** Type a path or use Browse for a fresh installation, including paths with spaces or Chinese characters. The default location is unchanged; your account must have write access to the selected folder.
- **Launch after installation.** Launch FluentControl is selected on the completion page. Clicking Finish opens the main panel; clear the checkbox to finish without launching. Silent installs, repairs, uninstalls and installations requiring a restart do not launch the app.
- **Choose startup behavior during setup.** Start with Windows is off by default for new installations. When enabled, FluentControl starts in the tray at sign-in. You can change it later in Settings → General. Upgrades detect the existing startup entry and let you keep or clear that choice.
- **Keep the existing folder on upgrade.** Setup restores the registered location instead of creating a second installation. To move the app, uninstall first and select a new folder on reinstall; personal settings remain intact.
- **Current icon in repository artwork.** The README and sharing-image asset now use the app's three-slider icon. GitHub's Social preview setting still requires a separate upload.
