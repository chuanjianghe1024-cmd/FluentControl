# FluentControl v0.3.145

## 中文

本次更新将自动调节作为主要功能独立呈现，并完善多设备接入和光照调节体验。

- **独立自动调节页面**：从侧栏进入“预设与调节”“设备与接入”“历史记录”。提供 USB 发现、Wi-Fi 配网、硬件选购与兼容说明入口。
- **多设备管理**：分别重命名、确认删除已保存的设备；同名设备显示 ID 和连接地址。重命名保留绑定身份及历史；删除非当前来源不打断当前规则，删除当前来源停止自动调节。删除订阅不会重置硬件，也不会清除历史文件或无线绑定。
- **稳定的光照档位**：用柱形编辑各光照区间的固定亮度，区间内不连续变化，跨过阈值后跳到对应亮度。3 点中值过滤短暂遮挡；保留写入限频及手动调节后的 10 分钟保持。
- **目标屏幕多选**：同一条规则可作用于多台显示器，各屏独立处理读回与失败；HDR 等原有安全限制仍然有效。
- **历史折线图**：按时间展示光照变化，缺测和无效采样处留空，并保留分页数值列表。查看其他设备的历史不切换当前光照来源。
- **引导式 Wi-Fi 配网**：设备检查、选择网络、输入密码、等待连接、验证无线读取、完成，共六步；失败可重试。验证成功后才添加无线订阅。
- **CH552 自动发现**：AUTO 纳入 CH55xDuino 的 USB 标识 1209:C550，仍要求 FC 固件协议握手；其他 USB 标识可指定 COM 端口。CH552 测试固件仅支持 USB 光照读取，不支持 Wi-Fi 或 USB 管理配置。

### 下载与升级

推荐下载 **FluentControl-0.3.145-x64-Setup.exe**；同时提供独立 MSI 和 SHA256SUMS.txt。仅 Windows x64，离线安装，升级保留现有配置和安装目录。

旧光照曲线和单屏选择会迁移，原配置备份到 `user-state.json.before-adaptive-bands-v2.bak`。迁移后光照自动调节暂停：请检查档位、选中目标屏幕，再手动启用。按时间调节保持原插值行为；v2 光照预设不能交给旧版 FC 导入。

## English

Automatic adjustment now has its own sidebar destination, with presets, device onboarding and history. Saved sources can be renamed or individually removed. Renaming preserves identity and history; removing the active source stops automation, while removing an inactive one leaves the current rule running. Removal does not reset hardware or erase wireless bindings/history files.

Ambient adjustment uses fixed brightness bands and a bar editor, with a three-sample median, rate limits and manual hold. One rule can target multiple displays with independent readback/fault handling. Light history uses a timestamped line chart with gaps for missing/invalid readings and paginated values.

A six-step Wi-Fi wizard guides discovery, network selection, credentials, connection, authenticated reading verification and completion, with retries. AUTO discovery includes CH55xDuino USB 1209:C550 candidates and still requires the FC handshake. CH552 test firmware provides USB light readings only, without Wi-Fi or device management.

Use **FluentControl-0.3.145-x64-Setup.exe** for offline Windows x64 installation; standalone MSI and SHA256SUMS.txt are also provided. Upgrades preserve configuration and the installation directory. Legacy ambient settings are backed up and migrated to v2 bands, with automation paused for review and explicit re-enabling. Time-based interpolation is unchanged; older FC versions cannot import v2 ambient presets.

The linked main build passed repository, Windows, native UI and installer validation. Existing physical C3/CH552 readings do not replace end-to-end testing of this release: real Wi-Fi setup, long-running multi-device behavior and physical display output remain to be checked. BLE, SoftAP, OTA and in-app flashing are unavailable. Installers are not Authenticode-signed.
