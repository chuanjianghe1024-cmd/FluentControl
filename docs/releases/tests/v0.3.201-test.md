## 内容与安装

- `FluentControl-0.3.201-x64-Setup.exe`：推荐的 Windows x64 安装包，内置 FCS Gateway。MSI 为替代安装入口，无需两个都安装。
- `FCS-Gateway-0.3.201-test-win-x64.zip`：独立 Gateway 便携包，无需安装 FC。该 ZIP 保留 CI 原始目录结构。
- FC 包含 node v2 传感器接入、亮度过渡曲线、可选远程 Gateway，以及 C3 USB 插件安装/配置/启停/回滚/安全模式/板端后台采样管理。
- Gateway 提供受限 Python 语法脚本的创建、校验、无副作用测试与条件触发；支持 WoL、显式 HTTPS 上传和 HA REST 接入。Windows 的复杂脚本功能另需 Python 3.10+，普通节点查询及 C3 插件管理不依赖 Python。
- Linux/Docker 部署在本标签源码的 `deploy/fcs`，已通过 amd64/arm64 CI；本次不额外发布未经对应构建验证的 Linux 二进制。

## 验证与限制

Windows 编译、窗口启动、脚本测试、MSI/Setup 安装/升级/修复/卸载，以及 Linux/Docker 和仓库检查均已通过。实际 C3/WoL、HA/HomeKit 配对及实体显示器仍需实机验收。HA 当前使用 REST 示例，没有 MQTT Discovery、原生米家认证或托管云账户服务。

插件与脚本默认禁用。电脑关机后，唤醒必须由独立供电的 C3 或其他常驻 Gateway 执行；发送成功不代表电脑已醒。测试前备份个人配置，回退使用原正式版安装包；不会自动降级。
