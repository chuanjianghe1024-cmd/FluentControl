# FluentControl v0.3.129-snap

## 中文

这是用于体验和反馈的 **Snap 预览版**（Windows x64 安装包，不是 Linux Snap 包）。自动调节默认关闭，请在「设置 → 自动调节预设」选择目标显示器和调节依据后启用。

### 本次重点

- **按时间调节亮度**：在 24 小时折线图上增加、拖动或输入亮度节点，午夜连续衔接；支持指定时区。
- **按日出日落调节**：选择地区快捷项或填写经纬度，在本地估算日出日落，设置日间与夜间亮度；可同时切换 FC 的浅色/深色主题。位置不上传，主题设置不影响 Windows 或其他应用。
- **订阅光照数据**：添加 HTTP/HTTPS 数据链接，让自己的传感器、第三方设备或模拟服务提供统一的 `fluentcontrol.light-sample` JSON；亮度曲线保存在本机，可导入导出。
- **无需硬件也能验证**：内置模拟光照；仓库另附 Python 本地模拟服务器和可编辑的时间—光照配置。模拟来源启用自动调节后也会实际改变所选屏幕的亮度。
- **平滑与手动优先**：默认 1 秒采样，3 点中值后平滑；屏幕最多每 2 秒写入一次，单次变化最多 5 个百分点，差异不足 2 个百分点不写。手动调整后暂停自动亮度 10 分钟。
- 同时收入正式版 v0.3.118 之后的 **笔记本内屏 WMI 亮度控制**、**应用主题选择与深色界面对比度修复**。

### 使用与边界

1. 首次建议选「光照强度 → 内置模拟光照」，编辑曲线并用预览滑块观察目标亮度。
2. 选择目标屏幕，开启「启用自动调节」进行实际测试；开启状态会保存，下次运行 FC 会继续。
3. 自建模拟链接：在仓库运行 `python tools/light-source/server.py`，订阅 `http://127.0.0.1:8765/light.json`。传感器之后按相同结构提供实时数据即可。

本版同时生效一条规则、一个目标屏幕。数据超时或无效时暂停；HDR 开启或状态未知时不自动写亮度；屏幕操作出错后需重新启用。仅预览图表不写屏幕。硬件 USB/BLE 桥接、固件和用户习惯学习尚未实现。

此安装包来自主干构建 #129，已通过完整 Windows、模拟界面、MSI 与 Setup 回归；这些检查不代表实体笔记本、HKC 显示器或传感器已通过实测。安装包未做 Authenticode 签名。此版不设为 Latest，软件内的正式版更新检查不会推荐它。安装会升级现有 FC，保留个人配置；旧版安装器可能拒绝直接降级。

## English

This **Snap preview** is a Windows x64 release, not a Linux Snap package. Automatic adjustment is off by default. Open Settings → Adaptive presets, select a display and mode, then explicitly enable it.

### Highlights

- Edit a 24-hour brightness curve with draggable or numeric points, midnight continuity and a selectable time zone.
- Calculate sunrise/sunset locally from a region shortcut or coordinates; choose day/night brightness and optionally switch FC between light and dark. Coordinates are not uploaded; Windows and other apps' themes are unchanged.
- Subscribe to HTTP/HTTPS illuminance feeds using the shared `fluentcontrol.light-sample` JSON format. Hardware, third-party devices and simulators use the same contract; brightness curves remain local and can be imported/exported.
- Test without hardware using built-in simulated light or the included Python localhost server and editable time/lux pattern. An enabled simulated source also controls the selected real display.
- Default 1-second sampling, a 3-sample median and smoothing, writes no more often than every 2 seconds, a 5-percentage-point step limit and a 2-point deadband. Manual adjustment pauses automatic brightness for 10 minutes.
- Includes changes since stable v0.3.118: laptop-panel brightness through Windows WMI, app theme selection and dark-mode contrast fixes.

### Getting started and limits

Try the built-in simulated source and preview slider, then choose a target display and enable automation. Enabled state persists across FC restarts. For an external test feed, run `python tools/light-source/server.py` and subscribe to `http://127.0.0.1:8765/light.json`.

One active rule and target display are supported. Invalid/stale data pauses control; HDR or unknown HDR state blocks automatic brightness writes. A display operation failure requires re-enabling. The curve preview alone never writes brightness. USB/BLE bridges, device firmware and preference learning are not included.

Main build #129 passed Windows, simulated UI, MSI and Setup checks; these do not establish compatibility with physical laptops, HKC monitors or sensors. Installers are not Authenticode-signed. This prerelease is not Latest and is excluded from stable in-app updates. It upgrades the existing FC installation while retaining settings; older installers may reject a direct downgrade.
