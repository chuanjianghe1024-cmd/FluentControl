## 中文

**少按几次显示器按钮，少打开几个系统设置页面。** FluentControl 用一个 Fluent 风格的 Windows 面板，把多屏调节、声音、麦克风和鼠标设置放到一起。

这是项目的首个正式版本，适合希望快速调整多台显示器、保存常用场景，并从桌面或快捷键完成日常操作的用户。

### 你可以用它做什么

- **一起调节多台显示器。** 不同型号也可整体调节，或切换到单屏操作。支持重命名、亮度映射及部分支持提示；亮度、对比度、色彩、输入、音量等控制按设备实际能力启用。
- **集中处理日常设置。** 在同一面板访问默认播放/通话设备、麦克风、鼠标速度和指针大小相关控制。
- **保存并分享常用场景。** 用分组及应用、型号、品牌标签整理配置，批量导入导出 JSON，或通过 HTTPS 链接下载；离线屏幕的设置继续保留。
- **把控制项留在桌面。** 半透明桌面面板可以移动、缩放和选择显示项目，双击解锁操作，锁定后保持在普通窗口下方。
- **按自己的习惯使用。** 支持托盘、单实例、可选自启动、跨组切换快捷键、八种语言和深浅主题。启动时并行初始化设备并缓存有效能力，当前数值仍从设备读取。

## English

**Spend less time pressing monitor buttons and opening separate settings pages.** FluentControl brings multi-monitor, audio, microphone and mouse controls together in one Fluent-style Windows panel.

This first release is for people who want to adjust multiple displays, save everyday setups and reach common controls from the desktop or keyboard.

### What you can do

- **Adjust multiple displays together.** Control different models as a group or adjust each screen individually. Rename displays, map brightness and see partial-support indicators. Brightness, contrast, color, input, volume and other controls are enabled according to actual device capabilities.
- **Keep everyday controls in one place.** Access controls for default playback/communications devices, the microphone, mouse speed and pointer size from the same panel.
- **Save and share profiles.** Organize profiles with groups and application, model or brand tags. Import/export JSON in batches or download through HTTPS links. Settings for disconnected displays are retained.
- **Keep controls on your desktop.** Move and resize a translucent panel and choose its visible controls. Double-click to unlock it; when locked, it stays beneath ordinary windows.
- **Work the way you prefer.** Use the tray, single-instance behavior, optional startup, cross-group profile shortcuts, eight languages and light/dark themes. Parallel device initialization and capability caching improve startup while current values are still read from hardware.

### Download and install

**[Download FluentControl-0.3.33-x64.msi](https://github.com/chuanjianghe1024-cmd/FluentControl/releases/download/v0.3.33/FluentControl-0.3.33-x64.msi)** · 48.03 MiB · Windows x64

Designed for Windows 11 x64; the installer minimum is Windows 10 2004 x64. The offline package includes the required runtimes, with no separate .NET or Node.js installation. Run the installer, then open FluentControl from the Start menu. It installs for the current user without administrator access.

When moving from an older portable version, exit it from the tray first and re-enable startup after installation to update the path. Upgrades and uninstalling preserve personal settings. For later improvements, visit the [latest stable release](https://github.com/chuanjianghe1024-cmd/FluentControl/releases/latest).

### Before you install

- Monitor adjustments require DDC/CI support throughout the device and connection path. Not every monitor exposes every feature; HDR and power-saving modes may also restrict controls.
- The installer is not code-signed. Windows may show an unknown publisher or SmartScreen prompt. A file checksum is not a substitute for a signature.
- Windows build, logic, simulated UI, tray, MSI install/upgrade/uninstall and settings-preservation checks passed. Compatibility with specific hardware still needs testing on those devices.
- Vendor SDKs, hardware crosshairs, game FPS, automatic profile switching by application and an online community client are not included. The companion sharing website is not live yet.

See the [project overview](https://github.com/chuanjianghe1024-cmd/FluentControl#readme) for future directions and reference projects. Feedback and compatibility reports are welcome in [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues); include your model, connection and reproduction steps.
