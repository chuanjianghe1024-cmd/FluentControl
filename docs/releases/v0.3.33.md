# FluentControl v0.3.33 · 首个正式版本

Windows 聚合控制中心：用一个 Fluent 风格面板调节显示器、声音、麦克风和鼠标。

## 下载与安装

下载本页附件 **FluentControl-0.3.33-x64.msi**，双击安装后从开始菜单打开。单文件离线安装包 **48.03 MiB**，自带必要运行库，无需预装 .NET 或 Node.js。面向 Windows 11 x64，安装器最低门槛为 Windows 10 2004 x64。

安装到当前用户目录，无需管理员权限。旧便携版请先从托盘退出；升级或卸载保留个人配置。安装后如需自启动，在设置中重新启用以更新路径。

## 本版内容

- 显示器亮度、对比度、色彩、输入、音量等 31 项通用 VCP 目录，按实际支持情况启用。
- 不同型号屏幕也能整体控制，支持单独调节、重命名、亮度映射和部分支持提示。
- 默认音频/通话设备、麦克风、鼠标速度和指针大小集中管理。
- 场景、分组、应用/型号/品牌筛选，批量 JSON 导入导出及 HTTPS 下载；离线屏幕设置保留。
- 半透明桌面面板，可移动、缩放和选择控制行；双击解锁，锁定时保持普通窗口下方。
- 托盘、单实例、自启动、跨组切换快捷键、八种语言和深浅主题。
- 优化启动读取：音频/鼠标/显示器同时初始化，最多两台屏幕并行读取；缓存有效能力，每次仍读取真实当前值。

此安装包来自已通过 Windows 构建、逻辑与模拟界面测试、真实 MSI 安装/升级/卸载、托盘和数据保留检查的产物，发布时直接复用原文件。
