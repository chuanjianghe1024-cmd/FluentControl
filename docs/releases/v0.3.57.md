# FluentControl v0.3.57

**第三个正式版本 · Third release**

[中文](#中文) · [English](#english) · [项目介绍 / About](https://github.com/chuanjianghe1024-cmd/FluentControl#readme)

## 中文

**双击即可操作桌面组件，声音跟随系统选择。** 本版汇总 **v0.3.50 → v0.3.57** 的更新，让常用音量控制更直接，也让多屏控制的支持状态更清楚。

### 本版亮点

- **桌面组件双击立即到前台。** 解锁时同时激活并前置，无需再点第三次；切到其他窗口或按 Esc 后重新锁定。Win+D 后也可以双击解锁，保留显示桌面时组件可见、不抢焦点的行为。
- **音频只保留「音量」「输入」。** 两项分别控制 Windows 当前默认输出和输入的音量与静音，不再展示设备名、其他设备列表或单独的通话设备。你在系统中选什么，FC 就跟随什么；Voicemeeter、NVIDIA Broadcast 等虚拟线路仍由你自己配置，FC 不干预路由。
- **切换设备后，配置仍然有用。** 新保存的总配置与桌面音频项跟随系统默认选择，外部音量、静音和默认设备变化会自动同步。输入或输出暂时不可用时，对应控制显示为不可用，配置中的已有值会保留。

### 多屏控制的改进

- **显示器菜单入口更清楚：** 即使屏幕未声明原厂 OSD 控制，也会保留适配状态栏目，并区分 FC 软件菜单与原厂菜单。可读取的标准状态仅供诊断，不会据此开放未经验证的菜单指令。
- **色温与场景模式反馈更准确：** 设置后等待并回读，未接受或返回不同值时显示实际结果与原始编码，不再误报成功；诊断记录补充型号身份与错误信息，便于后续适配。
- **型号配置库不再只显示已有预设的屏幕：** 已连接但尚未保存预设的型号也有分组与保存入口，同型号仍合并展示。
- **音量提示更明确：** 屏幕不支持 DDC/CI 硬件音量时，引导使用「音量与输入」中的系统音量控制。
- README 与发布说明统一为中英文产品介绍，工程结构、开发规范和详细计划集中维护在 `agent.md`。

### 验证与后续

Windows 自动化验收覆盖音频默认选择变化、外部音量与静音同步、缺失输入、旧配置迁移，以及真实鼠标双击前置、失焦锁定、Win+D、托盘和 MSI 安装/升级/卸载。实体 HKC 显示器、虚拟音频驱动、4K / 150% 和混合 DPI 多屏仍需本机验证。

原厂 OSD 遥控依赖经过验证的型号及固件适配，本版不代表已经解决所有 HKC 私有菜单或色温编码差异。在线适配库和报告提交服务尚未上线；安装包仍未签名。后续将继续完善型号适配和实机验证，问题反馈请到 [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues)。

## English

**Double-click to use the desktop panel, with audio following your system choices.** This release brings together the changes from **v0.3.50 → v0.3.57**, making everyday audio controls simpler and monitor support easier to understand.

### Highlights

- **Double-click immediately brings the desktop panel forward.** Unlocking activates and raises it without a third click. Switching to another window or pressing Esc locks it again. Double-click also works after Win+D, while Show Desktop keeps the locked panel visible without taking focus.
- **Just Volume and Input.** These control volume and mute for the current Windows default output and input. Device names, extra endpoint lists and separate communications devices are removed. Your Windows choices determine the targets; virtual routes such as Voicemeeter and NVIDIA Broadcast remain under your control.
- **Profiles follow device changes.** Newly saved audio settings and desktop controls use the current system defaults. External volume, mute and default-device changes synchronize automatically. Unavailable inputs or outputs are disabled without discarding their saved profile values.

### Better monitor feedback

- **Clearer menu support:** the monitor-menu section remains visible even when native OSD control is not advertised. It distinguishes the FC software menu from native-menu adaptation. Readable status alone never enables unverified commands.
- **More accurate color and picture-mode results:** settings are checked with bounded delayed readback. Rejected or different values show the actual result and raw codes instead of reporting success. Diagnostics include monitor identity and error details for adaptation work.
- **Every connected model appears in the preset library:** models without saved presets now have a group and a save action; identical models remain grouped together.
- **Clearer volume guidance:** displays without readable DDC/CI hardware volume point to system controls on the Volume & input page.
- The README and release notes now provide bilingual product introductions; engineering structure, conventions and detailed plans live in `agent.md`.

### Download and upgrade

**[Download FluentControl-0.3.57-x64.msi](https://github.com/chuanjianghe1024-cmd/FluentControl/releases/download/v0.3.57/FluentControl-0.3.57-x64.msi)** · 48.10 MiB · Windows x64 · Offline installer

Exit the old version from the tray before installing. Personal settings and startup choices are retained. Old desktop audio selections migrate to system controls after a backup. **Existing device-bound audio values in global profiles are retained but skipped: set Volume and Input as desired, then update each profile you want to keep using.** This avoids guessing which current route an old device setting should affect.

### Validation and next steps

Windows automation covers default-audio changes, external volume/mute updates, missing inputs, legacy migration, real mouse double-click activation, blur locking, Win+D, the tray, and MSI installation/upgrade/uninstallation. Physical HKC monitors, virtual audio drivers, 4K at 150% and mixed-DPI setups still need local hardware validation.

Native OSD control requires a verified adapter for the model and firmware; this release does not claim to resolve every HKC private-menu or color-code difference. Online adapter lookup and report submission are not live yet. The installer remains unsigned. Model adaptation and hardware validation continue; please report problems through [Issues](https://github.com/chuanjianghe1024-cmd/FluentControl/issues).
