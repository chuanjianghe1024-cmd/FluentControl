# FCS 平台架构规划 / FCS Platform Plan

> 规划文档，不代表通用 Gateway、插件运行时、规则引擎或云同步已实现。

## 定位与组件

FCS 是可扩展的设备与传感器平台，而非单一光照固件。FC 是首个集成客户端但不是设备运行的前提；FCW 网站源码仓库继续私有。

- **FCS Platform/Protocol**：统一设备、传感器、信号、端点、事件、动作、规则、错误和版本兼容。
- **Device Runtime**：运行在 ESP32-C3、RP2040、CH552 或未来硬件上的核心与驱动宿主；不假设所有主控都运行 MicroPython。
- **FCS Gateway**：可独立安装运行的后台进程，负责聚合发现、事件分发、规则执行和可选云同步。
- **FC Integration**：FC 默认安装包捆绑 Gateway 与管理界面；FC 主窗口提供设备/自动化页面，复杂流程可用子窗口。Gateway 也可单独安装。
- **fctrl.app**：未来提供插件/规则发现、版本与用户内容管理；网站源码保持私有。

## 对象模型

Device → Sensor → Signal → Endpoint，并配套 Event、Rule、Action、Plugin。

- Device：稳定设备身份，不因 USB、BLE、LAN 或 Gateway 路径改变。
- Sensor：设备内物理/逻辑实例；一台设备可有多个传感器，包括多个同类型实例。
- Signal：语义、类型、单位、量程与有效性明确的数据，例如 illuminance/lx、temperature/°C、relative_humidity/%RH、color_temperature/K、sound_level/dBA。
- Endpoint：访问路径；同一信号的多条路径仍指向同一身份。
- Event：带来源、类型、时间/序号、数据和协议版本的变化通知。
- Rule：声明式条件、时间窗、去抖、冷却、动作和失败策略。
- Action：已注册的动作，例如事件发布、Webhook、MQTT、Wake-on-LAN。
- Plugin：注册驱动、信号、事件处理、动作或诊断能力的扩展包。

## 插件、规则与权限

- 设备端可执行代码仅通过 USB 安装；LAN/BLE 不允许上传或替换 Python、MPY 或固件。
- 规则包可经授权无线通道下发，但只能引用已注册的信号、事件和动作；必须校验 schema、依赖与权限，不得夹带任意脚本。
- Gateway/FC 代码插件与设备端插件是不同运行目标。
- 目标是允许同网段客户端直接发现并读取公开的只读传感器数据；管理接口仍需授权。现有固件可能仍要求签名读取，目标行为尚未实现。
- MicroPython 插件共享解释器，没有可靠进程级沙箱。权限清单用于声明、审核与 UX，不能保证阻止任意 Python 代码。

## 事件与恢复

采样不等于事件。例如 18:00–22:00 内光照在配置时间窗上升超过阈值，经有效性、滤波、去抖和冷却判断后触发 light.rise；规则调用已安装的 WOL Action 并发布事件。发送成功不等于目标电脑已启动。需要在目标电脑睡眠时执行的动作应由 C3 或另一台常开 Gateway 执行。

插件先写 staging，验证大小、哈希、清单、目标平台、依赖与剩余空间，再切换活动版本；升级保留上一版，配置迁移失败时回退。重复崩溃的插件自动禁用；连续启动失败进入不加载第三方插件的安全模式，保留 USB 诊断和恢复入口。恢复出厂回到可信固件基线并清除第三方插件、规则、网络配置和用户授权。目录隔离只是组织措施，不是安全沙箱。

## FC / Gateway / 网站

- Gateway 通过版本化本机 API 与 FC 通信，优先使用受本机 ACL 保护的 IPC；Gateway 不要求 FC 常驻。
- 插件目录将来源、审核、可见性分开：官方/社区；官方审查代码/已在明确设备与固件上验证安装/未验证；用户内容公开/私有。
- 是否允许付费插件尚未决定。插件和用户发布内容的授权在未来网站条款中单独约定，不自动继承 FC/FCS 软件许可。
- 云端历史默认关闭，由用户明确选择信号、频率、保留期限；声音强度与原始音频必须区分。

## 阶段与验收

1. 版本化协议与模拟设备测试。
2. Gateway 最小可运行进程、本机 API、独立安装与 FC 默认捆绑。
3. 设备发现、只读信号、状态和事件总线。
4. 规则引擎、USB 代码插件管理、staging/回滚/安全模式。
5. 插件社区和可选云历史。
6. Windows 构建/安装验收、C3 实机测试、插件故障注入与恢复验收。

每阶段区分模拟验证、CI 验证和真实硬件验证；计划不能被写成已交付能力。
